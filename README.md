# NOTEd family links

Static landing page for NOTEd school family invitations (`/join/school#token=…`).
The invitation token stays after `#`, so it is never sent to this website.
No cookies, analytics or third-party scripts.

Generated from `web/school-links/` in the NOTEd app repository
(`npm run school-links:build`); edit there and republish, not here.
